 # **Unit 8: Summary**

You judge a workflow's value by human effort, cost, quality, and agreed limits, measured against how your team worked before.

## What you learned

In this module, you learned how to:

- Set a baseline, measurable targets, and acceptance criteria before automation.

- Check claims against evidence for the output version you review.

- Measure quality using the right groups, counting attempts separately from accepted outcomes.

- Calculate cost per accepted outcome, including all attempts and human work.

- Change one main factor at a time, record its version, and measure again on similar requests.
