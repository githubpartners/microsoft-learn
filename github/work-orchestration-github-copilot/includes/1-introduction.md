# **Work Orchestration with GitHub Copilot**

# **1. Introduction**

In this module, you learn how to orchestrate work with GitHub Copilot by turning a business request into executable work and selecting the right Copilot experience for the task. You explore how to define clear outcomes and acceptance criteria, provide the right context, choose an appropriate working surface, and adjust the level of agent autonomy based on the task.

You also learn how to select an agent and model, manage the context available to a Copilot session, and turn agent output into durable GitHub artifacts such as issues, pull requests, documentation, and project updates. Throughout the module, you consider how human oversight, permissions, risk, and traceability affect the way you use Copilot to complete real work.

## **Learning objectives**

By the end of this module, you are able to:

- Translate a business request into an actionable GitHub issue or work item

- Select the appropriate Copilot working surface based on the task and required context

- Choose an appropriate session mode based on task complexity, risk, and required level of human control

- Distinguish between Copilot agents and AI models and select an appropriate combination for a task

- Manage the context provided to a Copilot session, including files, issues, Projects, and documentation

- Turn Copilot output into durable GitHub artifacts and maintain traceability from the original request through human review

## **Prerequisites**

- A GitHub account

- A fundamental understanding of GitHub and GitHub Issues

- Familiarity with GitHub Copilot and its basic capabilities

- A basic understanding of software development workflows and pull requests
